# AdventureBros

## Academic Unity Game Project

AdventureBros is a 3D action-adventure game developed as part of a university Computer Science assessment.

The project was developed using Unity and C#, with a focus on gameplay programming, player interaction, combat mechanics, enemy behaviour, level progression and game systems.

## Game Features

- 3D player movement
- Jumping and sprinting
- Melee combat
- Enemy encounters
- Boss battles
- Player health and damage system
- Enemy health and damage system
- Coin collection
- Score tracking
- Multiple game levels
- Victory and defeat states
- Dynamic boss camera behaviour
- Gameplay audio
- Animation systems
- Main menu and level management

## 🛠️ Technologies
